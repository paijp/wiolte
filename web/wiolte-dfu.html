Chrome / Edge 専用（WebUSB）。Wio LTE を DFU モード（BOOT を押しながら RST を押して離す）にして program を押し、 一覧から「STM32 BOOTLOADER」を選びます。書き込み先（0x08000000 / 0x08010000）はファイルから自動判別します。 書き込み後はスケッチの USB シリアル（0483:5740）を表示します。初回は「シリアル接続」で選んでください。 Windows では DFU デバイスに WinUSB ドライバーが必要です（Zadig など）。Linux では udev の設定が必要です。
